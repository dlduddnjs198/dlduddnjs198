## Vision
- **신뢰를 설계하는 개발자**  
  단순히 기능을 구현하는 것을 넘어, 시스템이 안정적으로 동작하고 장애를 빠르게 복구하는  
  신뢰성 있는 구조를 설계하는 개발자가 되고 싶습니다.
- **문제를 끝까지 파고드는 개발자**  
  눈앞의 증상만 해결하는 것이 아니라,
  근본적인 원인을 찾아내고 재발을 방지할 수 있는 구조적 해결책을 고민합니다.
- **기술과 책임을 다하는 개발자**  
  개발은 결과만큼 과정도 중요하다고 생각합니다.
  주어진 역할에 최선을 다하고, 팀과 서비스의 흐름을 이해하며 책임감 있게 완성하는 자세를 지향합니다.

- **설명:** 식물 관리와 SNS 기능을 결합한 모바일 웹 서비스
- **인원:** 6인
- **기간:** 2024년 7월 ~ 2024년 8월
- **역할:** 백엔드 리더 및 인프라
- **기여:**
  - Redis 기반 캐싱 구현 → 조회수 및 좋아요, 날씨 데이터 처리 성능 개선
  - Jenkins와 Docker-Compose 기반 CI/CD 파이프라인 구축 및 자동 배포 설계
  - FCM 기반 푸시 알림 시스템 도입 및 이미지 저장을 위한 AWS S3 연동
- **성과:**

#### Newzy
- **설명:** 청소년들이 뉴스를 쉽고 재미있게 읽으며 시사 상식을 쌓을 수 있도록 돕는 웹 서비스
- **인원:** 6인
- **기간:** 2024년 8월 ~ 2024년 9월
- **역할:** 백엔드 리더 및 인프라
- **기여:**
  - ELK 기반 로그 분석, Elasticsearch 기반 실시간 단어 검색 시스템 설계
  - Redis Sentinel 아키텍처 및 Nginx 기반 Blue-Green 무중단 배포 환경 구현
- **성과:**
  - 고가용성 Redis + 중앙 로그 시스템 구축으로 운영 안정성 확보


#### TruthGuard (딥페이크 탐지/방해 솔루션)
- **설명:** 이미지에 노이즈를 삽입해 딥페이크 생성을 방해하고, 탐지 모델로 딥페이크 여부를 판단하는 **딥페이크 사전 방지 + 사후 탐지 솔루션**
- **인원:** 6인
- **기간:** 2024년 10월 ~ 2024년 11월
- **역할:** 백엔드 및 인프라 리더
- **기여:**
  - FastAPI 기반 학습 서버 및 배포 서버 구조 설계
  - MLflow 기반 학습/성능 기록 자동화 및 모델 버전 관리 체계 구축
  - 일정량의 이미지 수집 후 자동 학습 트리거 → 기존 모델과 성능 비교 → 자동 교체 배포 구조 설계
  - 모델, 데이터셋, 실험 이력을 EC2 로컬 디렉토리 + MLflow 메타데이터로 체계적으로 버전 관리
- **성과:**
  - 트리거를 활용한 모델 학습 및 성능 비교, 교체 배포까지 자동화된 MLOps 파이프라인 설계
  - DPG AI Challenge 경진대회 장려상 수상
