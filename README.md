## Vision
- **문제를 보는 시각을 가진 개발자**
    - 저는 항상 문제를 보는 시각을 가지고 인지하지 못했던 문제점을 찾고 해결하는 방법을 탐구하는 개발자가 되고 싶습니다.
- **완벽한 설계를 바탕으로 개발하는 개발자**
    - 저는 구현 과정 전에 요구사항 분석을 통한 최적의 프로세스를 설계하는 개발자가 되고 싶습니다.
- **지치지 않는 개발자**
    - 결과가 즉각적으로 보이지 않는다면 지치기 마련입니다. 저는 이러한 문제를 습관화를 통해 극복할 수 있는 개발자가 되고 싶습니다.

#### TruthGuard (딥페이크 탐지/방해 솔루션)
- **설명:** 이미지에 노이즈를 삽입해 딥페이크 생성을 방해하고, 탐지 모델로 딥페이크 여부를 판단하는 **딥페이크 사전 방지 + 사후 탐지 솔루션**
- **인원:** 6인
- **기간:** 2024년 10월 ~ 2024년 11월
- **역할:** 백엔드 및 인프라 리더
- **기여:**
  - FastAPI 기반 학습 서버 및 배포 서버 구조 설계
  - MLflow 기반 학습/성능 기록 자동화 및 모델 버전 관리 체계 구축
  - 일정량의 이미지 수집 후 자동 학습 트리거 → 기존 모델과 성능 비교 → 자동 교체 배포 구조 설계
  - 모델, 데이터셋, 실험 이력을 EC2 로컬 디렉토리 + MLflow 메타데이터로 체계적으로 버전 관리
- **성과:**
  - 트리거를 활용한 모델 학습 및 성능 비교, 교체 배포까지 자동화된 MLOps 파이프라인 설계
  - DPG AI Challenge 경진대회 장려상 수상
